# 🛍️ Lotus Retail Sales Dashboard

## 📌 Project Overview

Lotus Retail Sales Dashboard is an end-to-end Business Intelligence project developed in Power BI to analyze retail sales performance from 2022 to 2024. The dashboard combines sales, customer, employee, product, store, and return data to generate actionable business insights and support data-driven decision-making.

---

## 🎯 Business Objectives

- Monitor overall business performance.
- Analyze revenue, profit, cost, and order trends.
- Understand customer purchasing behavior.
- Evaluate employee performance.
- Identify return and refund patterns.
- Support strategic business decisions through interactive reporting.

## 📈 Key Insights

- Generated **45.35M EGP Revenue** over three years.
- Achieved **9.70M EGP Profit** with approximately **21% Profit Margin**.
- Processed more than **12K Orders**.
- Managed operations through **216 Employees** and **15 Stores**.
- Greater Cairo generated the highest revenue contribution.
- Bronze customers represented the largest customer segment (51%).
- October was the highest-performing month.
- Q3 delivered the strongest sales performance.
- Major return reasons included:
  - Wrong Item Delivered
  - Defective Product
  - Duplicate Orders
  - Changed Mind
  - Size Issues
  - Quality Issues

## 🏗 Data Model

This project follows a Galaxy Schema architecture.

### Dimension Tables
- Customers
- Products
- Stores
- Employees
- Date
- Orders

### Fact Tables
- Sales Orders (2022–2023)
- Sales Orders (2024)
- Order Details
- Returns

A dedicated Order Bridge Table was created to manage relationships between multiple fact tables and improve order-level analysis.
